# 本地开发文档

> 适用于「振凡命理」（快手磁力智投·姻缘测算 H5）项目本地开发服务器启动方式。

## 1. 仓库布局

- `G:/windows/yycs` — main 主干（前后端代码 + 文档，monorepo）
- `G:/windows/git-worktree/<hash>/frontend` — frontend 分支工作树（H5 前端：React + Vite + TS）
- `G:/windows/git-worktree/<hash>/rearend` — rearend 分支工作树（后端：Python + FastAPI）

端口：前端 `5173`、后端 `8000`；前端 `/api` 请求经 Vite 代理转发到后端。

## 2. 启动后端（FastAPI）

可在 main 根目录或 rearend 工作树执行（依赖已装则跳过安装步骤）：

```powershell
# 首次安装
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt

# 启动（热重载）→ http://127.0.0.1:8000
.venv\Scripts\python -m uvicorn app.main:app --reload
```

- dev 环境启动自动建表 + 种子产品；`BIRTH_DATA_KEY` 未配置时自动生成临时密钥（仅本地调试）
- 数据库：启动目录下自动创建 `app.db`（git 已忽略）

## 3. 启动前端（Vite）

可在 main 根目录或 frontend 工作树执行：

```powershell
npm install        # 首次
npm run dev        # 启动 → http://localhost:5173
```

## 4. 验证联调

```powershell
curl http://127.0.0.1:8000/api/health
# 期望: {"code":0,"message":"success","data":{"status":"ok"}}
```

浏览器打开 `http://localhost:5173`，走一遍 测算 → 下单 流程即可确认前后端联通。

## 5. 常用命令速查

| 用途 | 命令 |
|---|---|
| 前端启动 | `npm run dev`（换端口：`npm run dev -- --port 5174`） |
| 前端构建 | `npm run build` |
| 前端检查 | `npm run lint` |
| 后端启动 | `.venv\Scripts\python -m uvicorn app.main:app --reload`（换端口追加 `--port 8001`） |
| 后端测试 | `.venv\Scripts\python -m pytest` |
| 后端健康检查 | `curl http://127.0.0.1:8000/api/health` |

> PowerShell 提示：激活虚拟环境请用 `.venv\Scripts\Activate.ps1`（若被执行策略拦截，先运行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`）；或直接使用 `.venv\Scripts\` 下命令，无需激活。
