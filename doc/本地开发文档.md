# 本地开发文档

> 适用于「振凡命理」（快手磁力智投·姻缘测算 H5）项目本地开发环境搭建与日常启动。

## 1. 概述

本项目采用「主分支 monorepo + 开发工作树」模式：

```
G:/windows/yycs                                        main 分支：主干（规划/规则/文档 + 前后端代码，2026-08-12 起并入）
G:/windows/git-worktree/<hash>/frontend                frontend 分支：H5 前端（React + Vite + TS）
G:/windows/git-worktree/<hash>/rearend                 rearend 分支：后端服务（Python + FastAPI）
```

- `main` 为主干：前后端代码与文档统一存放（文件结构见 §4.3）；本地开发在对应工作树进行，代码提交至各自分支，审查通过后合并入 `main`
- 工作树仅包含本侧文件（`frontend` 工作树为前端工程，`rearend` 工作树为后端工程 + 接口文档）

本地运行拓扑：

```
浏览器/快手 WebView
   │
   ▼
Vite dev server (http://localhost:5173)   ← 前端，代理 /api
   │  /api/* (proxy)
   ▼
FastAPI (http://127.0.0.1:8000)           ← 后端
   │
   ▼
SQLite (<backend 启动目录>/app.db)   ← 本地数据库
```

- 前端端口：`5173`；后端端口：`8000`
- 数据库：SQLite（开发期），文件位于**后端启动目录**根目录 `app.db`（rearend 工作树或 main 根目录，`.gitignore` 已排除）
- 本期本地开发**不需要**微信商户号、ICP 备案、企业微信权限等外部资质

## 3. 前端本地开发（frontend 工作树）

工作树目录：`G:/windows/git-worktree/<hash>/frontend`（后续以 `<frontend>` 代指）

```bash
cd <frontend>
npm install        # 首次安装依赖
npm run dev        # 启动 Vite dev server → http://localhost:5173
```

其他命令：

```bash
npm run build      # 类型检查 + 生产构建（tsc -b && vite build）
npm run lint       # oxlint 静态检查
npm run preview    # 预览生产构建产物
```

环境变量（`.env.development`，已提交）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `VITE_API_BASE_URL` | `/api` | API 基础路径；dev 下经 Vite 代理转发到本地后端 |

> 本地新增密钥类环境变量放 `.env.local`（已被 `.gitignore` 的 `*.local` 排除），勿提交。

## 4. 后端本地开发（rearend 工作树）

工作树目录：`G:/windows/git-worktree/<hash>/rearend`（后续以 `<rearend>` 代指）

### 4.1 首次安装（一次性）

```bash
cd <rearend>
python -m venv .venv          # 项目内创建虚拟环境
source .venv/Scripts/activate # bash 激活（Windows）；cmd/powershell 见下注
pip install -r requirements.txt
cp .env.example .env          # 如已有 .env 则跳过
```

> 注：`.venv/` 与 `.env` 已被 `.gitignore` 排除，不会提交。
> cmd 激活：`.venv\Scripts\activate.bat`；PowerShell：`.venv\Scripts\Activate.ps1`。

### 4.2 配置项（.env）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `APP_NAME` | 振凡命理 | 应用名（API 文档标题） |
| `APP_ENV` | dev | 环境标识 |
| `DEBUG` | true | FastAPI debug 模式 |
| `DATABASE_URL` | `sqlite:///./app.db` | 数据库连接串（开发期 SQLite） |
| `CORS_ORIGINS` | `["http://localhost:5173","http://127.0.0.1:5173"]` | 允许跨域来源（JSON 数组） |
| `BIRTH_DATA_KEY` | 空 | 生辰数据加密密钥（AES-256-GCM，`openssl rand -base64 32` 生成）；dev 未配置时自动生成临时密钥（重启失效），prod 未配置启动报错 |

> 微信支付/企业微信密钥上线前配置，禁止入库、禁止进 `.env.example`。

### 4.3 启动与测试

```bash
source .venv/Scripts/activate   # 每次新终端需先激活
uvicorn app.main:app --reload   # 启动 → http://127.0.0.1:8000（热重载）

python -m pytest                # 运行测试
```

## 5. 前后端联调

1. 启动后端：`cd <rearend> && source .venv/Scripts/activate && uvicorn app.main:app --reload`
2. 启动前端：`cd <frontend> && npm run dev`
3. 前端 `/api/*` 请求经 Vite 代理转发到 `http://127.0.0.1:8000`（`vite.config.ts` 的 `server.proxy`）

> 也可在 main 工作树直接启动（前后端文件齐备），但需自行安装 node_modules 与 .venv；日常开发仍建议在对应工作树进行。

验证：

```bash
# 后端健康检查
curl http://127.0.0.1:8000/api/health
# 期望: {"code":0,"message":"success","data":{"status":"ok"}}

# 浏览器访问前端
open http://localhost:5173
```

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 端口被占用 | 前端 `npm run dev -- --port 5174`；后端 `uvicorn app.main:app --reload --port 8001`（CORS/代理需同步调整） |
| Python 3.14 依赖安装失败 | 确认有 pydantic-core 等预编译 wheel；仍失败则降级 Python 3.13 重装 venv |
| Git 提示 LF will be replaced by CRLF | 正常警告（Windows 换行符差异），不影响功能 |
| 请求 `/api/*` 404 | 确认后端已启动且 `vite.config.ts` 代理配置存在（见 §5） |
| `.env` / `.venv` 被 git 忽略 | 正常，本机独有文件一律不提交；新增密钥只放 `.env` 不放 `.env.example` |
| 工作树中 `AGENTS.md` 未跟踪 | 正常，为本地规则文件（.gitignore 排除），代理开发依赖它 |
