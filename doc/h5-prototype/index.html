页面分解 · Page Breakdown

每页均可在左侧手机中点击体验 · 此处为设计要点

01 Landing · 首页 — 第一眼定调⌄
三层罗盘（外虚线顺时针 38s / 内实线逆时针 26s / 八卦 22s / 太极 4s）营造玄学呼吸感；Ticker 每 3.5s 淡入淡出 + 悬停暂停；Bento 卡 stagger 入场 + 悬停微抬；主 CTA 流光每 3.2s 一次，克制不廉价。
02 Calc · 测算 — 表单顺滑⌄
历法胶囊用布局动画（layout）平滑切换；输入聚焦 3px 金色光晕 + 震动校验（x 抖动 120ms）；标签选中 spring 弹入；提交按钮按压 0.97 + 触觉反馈预留。
03 Loading · 推演 — 等待不焦虑⌄
全屏沉浸 + 太极加速（12s/8s）+ 步骤逐条点亮 + 进度条 spring 宽度；百分比 tabular-nums；超时抽屉 spring 弹出，保留数据。
04 Order · 订单 — 信任与对比⌄
命盘预览卡 + 密签节选降低决策焦虑；产品卡选中态 ring + 对勾弹入；价格划线动效；支付方式网格按压反馈。
05 Pay · 支付 — 紧迫与清晰⌄
倒计时 tabular-nums + 脉冲点；二维码扫描线（shimmer）暗示可扫；codeUrl 可长按复制；CTA “我已支付” 常驻吸底。
06 Report · 报告 — 长文可读⌄
章节视口渐显（whileInView once）；四柱网格 + 喜忌高亮；锁定态毛玻璃 + 金锁呼吸；吸顶章节导航（待接入）+ 进度条；企微活码卡悬停微抬。
