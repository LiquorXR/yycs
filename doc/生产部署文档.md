# 振凡命理 · 生产部署文档（Docker Compose）

> 适用范围：单台云主机。前端静态产物 + 后端 API 容器化；TLS/nginx 反代由运维在主机上手动配置（项目内不处理）。

## 1. 架构

```
DNS → 服务器 IP（防火墙放行 80/443）
        │
主机 nginx/NPM（手动配置，如 Nginx Proxy Manager）：仅 TLS 终止 + 统一反代 → 服务器内网 IP:8000
        │
backend 容器（uvicorn :8000，映射宿主机 0.0.0.0:8000）：托管前端静态产物 + API，SQLite 卷 /data/app.db
        │
一次性服务：frontend-build（构建 dist 入命名卷 frontend_dist）、migrate（alembic 迁移 + 幂等种子）
```

- 前端 SPA（`/assets/*`、`index.html`）由 backend 内 FastAPI 托管：`/assets` 走 StaticFiles，其余非 API 路径回退 `index.html`（`/api`、`/docs` 前缀一律 JSON 404）
- 主机 nginx/NPM 只需一个 Proxy Host：域名 → `http://<服务器内网IP>:8000`（SSL 面板内开启证书），无需静态 root 与自定义 location；注意 NPM 容器内的 `127.0.0.1` 指向容器自身回环，不可作为反代目标，须用服务器内网 IP（或同 Docker 网络内的服务名 `backend:8000`）；若反代以宿主机进程运行，可直接用 `127.0.0.1:8000`

## 2. 文件说明

| 文件 | 用途 |
|---|---|
| `docker-compose.yml` | 编排 frontend-build / migrate / backend |
| `Dockerfile.backend` | 后端镜像（python:3.12-slim + uvicorn，非 root 运行） |
| `Dockerfile.frontend` | 前端构建镜像（node:22-alpine，运行时构建产物 → 命名卷 frontend_dist） |
| `scripts/init_prod.py` | migrate 服务入口：alembic 迁移 + 幂等种子 |
| `.dockerignore` | 构建上下文排除项 |
| `.env.production.example` | 生产环境变量模板（服务器上复制为 `.env` 后仅需改密钥与域名） |

## 3. 首次部署

```bash
# 前置：Docker Engine + compose 插件已安装
git clone <repo> /opt/zhenfan && cd /opt/zhenfan
cp .env.production.example .env

# 编辑 .env（仅需修改两处）：
#   BIRTH_DATA_KEY=<openssl rand -base64 32 生成>
#   CORS_ORIGINS=["https://你的域名"]

docker compose up -d --build
```

首次构建约 3-5 分钟。`frontend-build`（执行 npm run build 落盘命名卷 frontend_dist）与 `migrate`（迁移+种子）运行完成后退出（exit 0），`backend` 保持运行。

## 4. 验证清单

```bash
docker compose ps
# backend healthy；frontend-build/migrate 退出码 0（restart: no，预期状态为 Exited 0）

curl https://你的域名/api/health
# {"code":0,"message":"success","data":{"status":"ok"}}

curl https://你的域名/api/products
# 应包含「姻缘测算完整报告 ¥99」与「姻缘测算免费版」两条种子数据

浏览器：落地页 → 测算 → 下单 全链路
```

## 5. 升级发版

```bash
git pull
docker compose up -d --build
```

- 自动重新执行 migrate（幂等：表已存在则跳过；种子已有则跳过）
- SQLite 卷、命名卷 frontend_dist 均保留；证书由主机 nginx/NPM 自管，不受影响

## 6. 备份

```bash
# SQLite 冷备（建议 cron 每日 + 保留 7 份）
docker run --rm -v zhenfan_app_data:/data -v /opt/zhenfan/backup:/backup alpine \
  cp /data/app.db /backup/app-$(date +%F).db
```

**密钥备份**：`BIRTH_DATA_KEY` 与数据库备份一并异地保存（丢失后历史生辰密文不可解密）。

## 7. 日志

```bash
docker compose logs -f backend        # 后端日志
docker compose logs migrate           # 迁移/种子日志
```

## 8. 回滚

```bash
git checkout <旧版本 sha> && docker compose up -d --build
```

迁移回滚需评估 alembic down_revision（当前仅初始迁移）。首次部署失败可直接 `docker compose down -v` 清卷重来。

## 9. 注意事项

- backend 必须保持**单副本**（SQLite 单写锁）；流量上来后需迁移 PostgreSQL
- 数据库连接串为容器内绝对路径 `sqlite:////data/app.db`，勿改回相对路径
- 前端产物由 frontend-build 写入命名卷 `frontend_dist`，backend 以只读方式挂载（`/app/dist:ro`）并在启动前等待其完成；nginx/NPM 无需指向任何静态目录
- 容器以非 root 用户（uid 10001）运行；named volume `app_data` 首次创建时继承镜像内 /data 属主
- 端口 8000 映射宿主机 0.0.0.0（容器化反代如 NPM 需经服务器 IP 访问 backend）；公网防护依赖云安全组/主机防火墙：仅放行 80/443，禁止 8000 入站；反代若部署在宿主机进程，可将映射收紧回 `127.0.0.1:8000:8000`
- 快手 WebView 投放与微信支付回调均要求 HTTPS，域名证书须就绪
